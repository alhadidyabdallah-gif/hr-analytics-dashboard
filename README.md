# 👥 HR Analytics Dashboard

## 📊 Project Overview
An end-to-end HR analytics project analyzing **500 employees** across 10 departments, using SQL and Power BI to uncover insights about salaries, performance, attendance, and turnover.

## 🎯 Business Problem
- High employee turnover in specific departments
- No clear visibility into salary benchmarks and performance metrics
- Difficulty identifying high-performers and at-risk employees

## 🛠️ Tools & Technologies
- **MySQL:** 4 interconnected tables (employees, departments, attendance, performance)
- **SQL:** Advanced analytics (Turnover Rate, Performance Analysis, Age Groups)
- **Power BI:** DAX measures, KPI Cards, Treemap, Waterfall Chart
- **Data Storytelling:** Recommendations for HR leadership
